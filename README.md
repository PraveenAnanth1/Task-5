## 🌳 Decision Trees and Random Forests - Heart Disease Prediction

### 📌 Objective
This project demonstrates how to use **Decision Tree** and **Random Forest** classifiers to predict the presence of heart disease based on various health features.

---

### 🛠️ Tools & Libraries Used
- Python
- Pandas
- Scikit-learn
- Matplotlib

---
### 🧪 What the Code Does
1. Loads the dataset using **pandas**
2. Splits the data into training and testing sets
3. Trains a **Decision Tree Classifier**
4. Visualizes the decision tree using **matplotlib**
5. Trains a **Random Forest Classifier**
6. Compares accuracy of both models
7. Shows **feature importances** for the Random Forest
8. Evaluates using **cross-validation**

---


### 📈 Output
- Visual tree plot of the Decision Tree
- Bar chart of important features
- Accuracy of both models
- Cross-validation scores
